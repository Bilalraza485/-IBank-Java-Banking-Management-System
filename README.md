🏦 IBank – Java Banking Management System

A desktop-based Banking Management System built in Java.
IBank enables staff and customers to perform essential banking tasks such as account management, deposits, fund transfers, and reporting through an intuitive GUI.
Designed using Java Swing with .form files for layout (NetBeans recommended).

🌟 Motivation

Managing day-to-day banking operations manually can be time-consuming and error-prone.
IBank was created to automate these operations with a simple, user-friendly interface.
This project also demonstrates my learning of Object-Oriented Programming and GUI development in Java.

📑 Project Highlights

Platform: Desktop application

Technology: Java (JDK 8+) with Swing GUI

Purpose: Provide core banking features for staff and customers

Focus: Account management, transactions, and reporting

Goal: Learn how to integrate multiple modules into a cohesive banking system

🧠 How It Works
1️⃣ User Authentication

Secure login for administrators and customers.

Different menus for staff and users after login.

2️⃣ Account & Customer Management

Create new accounts and store customer information.

Update and view existing customer records.

3️⃣ Transactions

Perform deposits into accounts.

Transfer funds between accounts securely.

4️⃣ Reports

Generate simple customer reports.

Display transaction details for auditing.

5️⃣ GUI Design

Designed with Java Swing and NetBeans Form Designer.

.form files define the layout; .java files implement logic.

🚀 Project Structure
Module	Purpose
Login / LoginUser	Admin & user login screens
MainMenu / USERMainMenu	Navigation menus after login
Account	Account creation & management
Customer	Manage customer information
Deposit	Deposit transactions
Transefer	Funds transfer between accounts
